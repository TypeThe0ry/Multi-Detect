# YOLOE v3 候选框模型（2026-10-17）

快系统候选框模型从 `yoloe-v2-r3-seg-drop-full` 换成 `yoloe-v3-onboard-1280`（YOLOE-11s，1280 输入，25 轮；训练数据是 r3 的 2.3 倍，加入了易混物体场地的飞行画面；测试留出类 stop_sign / postbox / pickup 的图像不进训练）。权重：`artifacts/experiments/yoloe-v3-onboard-1280/train/weights/best.pt`（SHA-256 `402d91abcaf924ab22971ac9b9130843109fa8821dfbfd88c0c52d574f9e89a4`），评估原始输出在同目录 `round-eval/`。

## 新旧对比（同一测试世界、同一口径）

测试世界 888 帧（`eval-v2-test-r12multi`、`eval-v2-test-r8multi`），类无关候选，置信度 0.05，一对一匹配 IoU ≥ 0.3：

| 指标（1280 输入） | 旧 v2-r3 | 新 v3 | 变化 |
|---|---:|---:|---:|
| 全体召回 | 81.4% | **91.2%** | +9.8 |
| 候选框短边 < 8 px | 57.2% | **79.2%** | +22.0 |
| 8–16 px | 98.6% | 99.7% | +1.1 |
| 16–32 px | 98.8% | 99.1% | +0.3 |
| 32–64 px | 95.5% | 100% | +4.5 |
| 未见类 stop_sign | — | — | +29.5 |
| 未见类 postbox | — | — | +9.1 |
| 未见类 pickup | — | — | 0 |

960 输入时全体 82.3% → 87.9%，< 8 px 59.2% → 71.0%。

小目标样本（200 帧，机上过滤口径）：每帧候选数基本不变（1.87 → 1.89），误报更少（场景误报每帧 0.06 → 0.035）；CPU 单次推理耗时基本不变（0.31 s，开发机 CPU，不代表 Orin）。r3 可比缓存 6,462 帧键集合与旧缓存完全一致。

## 结论与影响

- 机上默认候选框、Orin 基准脚本和 Orin 导出脚本已切换到 v3。
- 慢模型轮次评测（`run_model_round_eval.py`）暂时保留旧候选框，保证和 r12/r13/r14 的结果可比；下一轮慢模型（r15）开始统一换成 v3 并重新建立基线。
- 极小目标召回大幅提高，正好对应慢模型分析里“小于 12 px 的候选看不清”的问题：现在更多极小目标会被发现，但慢模型能否认出它们仍取决于 r15。
- 仍需：在 Orin Nano 上导出 TensorRT 引擎并实测耗时；用仿真闭环飞行验证端到端效果（需要 C: 盘空间）。
