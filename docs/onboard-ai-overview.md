# 机上 AI 总览（2026-10-15）

一句话：飞机只拿到一句任务（比如“数一数场地里有几个交通锥，然后返航”），自己理解任务、搜索、判断、执行、返航。全程不看答案——仿真里的真值只在飞完以后用来打分。

以下成绩全部来自 Gazebo + PX4 软件在环仿真（SIM），开发机是 RTX 4060；**还没有在 Jetson Orin 上实测，也没有上真飞机**。

## 它是怎么“思考”的

```
相机画面 ──> 快系统：检测器（YOLOE）每帧给出“可能是东西”的候选框
                │
                ▼
          主机：把候选框跟踪成稳定的目标（按地面位置），决定问慢系统哪一个
                │                         ▲
                ▼                         │ “是 / 不是 / 再靠近看看”
          慢系统：一个约 1.3 GB 的小视觉语言模型（Qwen3-VL-2B 微调）
                │  ① 起飞时把一句话拆成任务计划
                │  ② 飞行中判断某个候选“是不是任务要找的东西”
                ▼
          主机：决定接近、确认、执行技能（搜索/计数/绕拍/巡逻…），检查静态地图避障
                │
                ▼
          飞控 PX4：执行有界的动作（转向、平移、升降、悬停、停止）
```

- **快系统**只负责“找出可能的东西”，不认类别：对训练里出现过的类别，候选召回 99%；训练中从没当过目标的类别，召回 67%。
- **慢系统**只回答“是不是”，以及在起飞时编任务计划；它从不直接控制电机。
- **主机**决定远近和确认：例如要求从两个视角都判“是”，40 m 以外的“是”只算“继续靠近”，靠到不能再近时才按身份确认。
- 理解任务和判断目标用的是**同一个模型**（v2-r8-multi，Q5_K_M 量化 1.26 GB + 0.45 GB 视觉投影），适合 Orin 8 GB。

## 会做哪些任务

| 技能 | 作用 | 状态 |
| --- | --- | --- |
| area_search 搜索 | 在区域里找一个符合描述的东西 | 已实现，仿真验证 |
| count 计数 | 在区域里数同类东西（同一位置只算一次） | 已实现，仿真验证 |
| inspect 绕拍检查 | 绕找到的东西从多个方向拍照、再判断 | 已实现，仿真验证 |
| patrol 巡逻 | 沿给定航线飞若干圈，看到目标就告警 | 已实现，仿真验证 |
| monitor 监视 | 到区域中心悬停扫视一段时间，看到目标就告警 | 已实现，仿真验证 |
| survey 测绘 | 在区域内按“之”字航线覆盖拍照 | 已实现，单元测试 |
| follow 跟随 | 跟住找到的目标并保持距离 | 已实现，单元测试 |
| goto / hover / record / return_home / land | 前往、悬停、记录证据、返航、降落 | 已实现 |
| deliver 投送 | 投放载荷 | 需要单独授权，未实现 |

一句话任务的例子（都已在仿真里完整跑通）：“数一数场地里有几个交通锥，然后返航”“找到邮筒，从四个方向拍照检查，然后返航”“监视场地五分钟，看有没有背包”“沿着围栏巡逻一圈，注意有没有背包”。地点（场地、围栏路线等）由地面提供名称和范围，模型只能引用已知地点。

## 目前的成绩（仿真）

### 找单个目标

6 个测试世界，目标类别（停车标志、SUV、两种行人、皮卡、邮筒）在训练里**从没当过目标**，每个世界飞 2 次，共 12 次：

| 版本 | 成功 | 按任务语义 | 真正的误确认 | 没确认 |
| --- | --- | --- | --- | --- |
| 最早（r3-seg 慢模型） | 2/12 | — | 1 | 9 |
| 主机修复后（地面锚定跟踪、保持在视野内、被拒焦点不悬停） | 6/12 | 8/12 | 3 | 1 |
| 当前机上模型 v2-r8-multi | 6/12 | 8/12 | 2 | 2 |

找到时位置误差多在 0.3–0.6 m。“按任务语义”多出的 2 次是任务有歧义：任务说“找到人”，场景里有两个人。

### 一句话任务（端到端，v2-r8-multi，每项 1 次飞行）

| 指令 | 编出的计划 | 结果 |
| --- | --- | --- |
| 数一数场地里有几个交通锥，然后返航（3 个） | 计数 → 返航 | 数到 2 个，0 误报，返航 |
| 找到邮筒，从四个方向拍照检查，然后返航 | 搜索 → 绕拍 → 返航 | 找到（误差 0.11 m），4 张照片，返航 |
| 监视场地五分钟，看有没有背包（3 个） | 监视 → 返航 | 报出 2 个真背包 + 1 个误报（电箱） |
| 沿着围栏巡逻一圈，注意有没有背包 | 巡逻 → 返航 | 报出 2 个真背包 + 1 个误报（电箱），返航 |

| 能力 | 当前（v2-r8-multi） |
| --- | --- |
| 判断“是不是任务要的东西”（243 条测试） | 94.1% 正确，干扰物拒绝 89.9% |

## 已知问题和下一步

- **相近东西认错**：诊断工具（`scripts/review_slow_mistakes.py`）在当前模型的飞行记录里发现：同一个电箱被当成背包 18 次，SUV 被当成皮卡 16 次。用飞行中低空画面再训练（v2-r9-multi）结果有好有坏，正在用任务套件多次飞行对比。
- **小目标在巡航高度看不见**：停车标志在 19–27 m 高度只有几个像素；按尺寸降低搜索高度后仍不够（竖着的牌子从上往下看很窄）。
- **任务文字歧义**：部分仿真世界里“找到人”同时有两个人；新生成世界已能避免。
- **中文任务理解弱于英文**：60 条新任务里中文 21/30、英文 25/30（修正约束解码后；之前“数一数”常被编成巡逻，原因是解码语法与训练时的参数顺序不一致）；补充“清点/跟随/拍照记录”等说法的第一版数据（plan-sft-v3）漏掉了几种技能，训出的模型反而变差（83% → 50%）；已改成新旧说法混合（plan-sft-v4），v2-r11-multi 训练中。
- **Orin 未实测**：基准工具已就绪（见下），需要在 Orin 上跑一次。
- **真实飞机未验证**。

## 怎么复现

```
# 找单个目标：6 个测试世界各 2 次
python scripts/eval_onboard_loop_campaign.py --episodes 2 --steps 80 --onboard-config configs/onboard/sim-loop-v2r8multi.json --out <输出目录> --report <报告.json>

# 一句话任务套件（计数、监视、巡逻、绕拍、测绘、找到并降落、英文指令）
python scripts/run_mission_suite.py --suite configs/onboard/mission-suite-v1.json --episodes 2 --out <输出目录>

# 规划评测（30 条 / 60 条手写任务）
python scripts/plan_from_task.py --gguf <模型.gguf> --sorted-keys --output <结果.json>
python scripts/plan_from_task.py --gguf <模型.gguf> --sorted-keys --tasks configs/onboard/plan-eval-tasks-v2.json --output <结果.json>

# 慢系统认错了什么（生成带裁剪图的 HTML 报告）
python scripts/review_slow_mistakes.py <飞行记录目录> --only-mistakes --out <输出目录>

# Jetson Orin 基准（在 Orin 上运行，说明见 docs/orin-onboard-benchmark.md）
python scripts/bench_orin_onboard.py --help
```
