# OnboardAI：模型可复现，但跨场景行动能力未通过

2026-10-08 07:37。目前仍不是已经能自主飞行的模型。

## 已真正完成

这轮267次训练正常结束；另一个进程重新加载实际保存的权重，也正常结束。保存前后86条
原始预测逐条一致，包括模型生成的token、实际图像输入和评分，没有用内存中旧模型冒充重载。
完整日志、33个周期检查点与最终保存都通过检查；之前失败消耗的13次仍计入累计280次，
没有把训练成本归零。[完整记录](evidence/onboard-navigation-recovery267-terminal-20261008-r2.json)
保留文件身份、实际退出和独立复核的来源。

但模型判断不可靠：86条训练内样本里，动作只对27条，停止0／3；旧warm模型动作对55条。
格式变好了，不能掩盖行动退步。这批数据仅3条任务路线，继续重复相同训练没有足够依据。
候选保持隔离，不替换默认模型，不接PX4执行。

## 新场景已实际评估，结果未通过

本机GPU已完成另外场景的59条原始图像推理：17条开发验证、42条开发测试。
模型只看任务文字、当前RGB和最近过去的RGB；姿态答案、后续画面、正确动作都在模型外。
另外23条训练侧数据不参加这轮评估，不能依据测试答案追加训练。

这批数据也来自发布者的TRAIN分区，因此只是内部跨场景开发检查，不是官方未知场景测试。
完整推理与分析均正常退出，独立复算原始结果和输入身份通过。
[真实评估记录](evidence/onboard-navigation-original59-actual-evaluation-20261008-r1.json)
保留实际退出、来源和评分范围。

| 检查 | 正确／样本 |
| --- | ---: |
| 输出格式 | 59／59 |
| 下一步动作类别 | 16／59 |
| 动作及距离／转角 | 0／59 |
| 开发验证集动作 | 15／17 |
| 开发测试集动作 | 1／42 |
| 停止动作 | 0／2 |

也就是说，模型能写出格式，但新场景里常选择错行动，不能据此让无人机自动飞。
16条可比较前进预测的平均位移误差5.5米，另外38条前进样本连行动类别都错，不能用
这个局部平均掩盖失败。报告每次生成均值5.826秒并不包括全部图像预处理和在线链路，
也没有在Jetson上测过，不能当实时飞行性能。

下一批6条原始3-D路线已实际完成122原图解码、原姿态位移和逐步标签核对，独立复算通过；
116个下一步＋6停止，来源和几何审核通过但还未完成训练准入。
[新数据说明](onboard-navigation-indexed-training-data-20261008.md)明确这个边界。
已索引的120条路线／4077候选帧则仍只是发现结果，不是全部已取得。

同一视觉语言底座上的小型动作读出组件已完成软件测试，但尚未在真实模型特征上训练。
它是用来比较“直接学习行动”与“生成动作文字”的实验，不是用固定前进距离填补判断。

[公开模型研究](onboard-pretrained-navigation-search-refresh-20261008.md)同时比较大型导航
模型、小型机载模型和历史记忆压缩。只有公开可验证的权重、实际资源与质量结果，才支持
