# 从模拟观测走向真实动作训练（2026-10-08）

## 本轮完成什么

先前 Gazebo/PX4 已能提供真实相机画面和合格的地面待命观测，但这些观测还不能直接编成
教师飞行任务。本轮补上了“检查原始观测 → 明确模拟预算 → 编译有界动作路线”的软件链，
并修复了教师会话编号与 Mission 上传／回读响应编号不一致的问题。

这不是又训出一个模型，也不是已经起飞。它是取得下一批可靠行动训练数据所需要的入口。

## 不把未知量变成假传感器值

plain x500 没有可信的剩余航时和空速来源。现在可以为一个固定版本、固定场景的模拟
飞机明确声明能量假设和保守巡航能力。输入文件必须写清单位、适用电量／风速范围和
来源，实际读取并核对文件大小与 SHA；派生时保留原 GPS、HOME、电量、接收时间和
资源状态。空速仍可未知，不补零、不声称装了空速传感器，也不覆盖已有实测续航。

每次编译按当前时刻重算预算，返回任务实际绑定的新预算回执；不刷新观测时间。
返航余量仍只由原规划器扣一次，已消耗的时间全额扣除，不随剩余比例缩小保护余量。
模拟假设只适用于 SIM，不能拿来批准 HIL／REAL。
本轮没有为实际场景凭空填写一个“可飞”的预算文件，也没有宣称实测标定。

## 拆掉一个不必要的旧限制

普通目标搜索必须有识别能力；采集训练轨迹的教师路线没有目标识别分支，不必先启动
YOLO 才能规划。新增入口仅允许多旋翼、明确的 SURVEY 路线、无 detection 分支、结束
返航、保持围栏约束；`perception=false` 可以原样保留。

这不是关闭安全检查：相机、GPS、围栏、地图／地形、风、保守能力和剩余预算依旧
检查。地图／DEM 文件存在本身不代表飞行路线净空合格；下一步必须核验实际世界的
碰撞几何、地图与 EKF 原点，以及包含起飞／返航／降落的完整路线和不确定性裕量。
尚未实现可信的静态净空替代入口，所以没有把这些布尔值偷偷改成 `true`。

## 新版 Mission 只在明确范围内编译

新版观测不再被一概拒绝，但只为已迁移的多旋翼 SIM 入口开放。绑定记录检查原始
观测时间、同一时钟、当前有效期、任务／路线／安全配置、机型、模拟域、运行身份
与规划来源。编译前重新读取并重算原观测回执及其所列原件、模型文件和派生结果。
仅提供一个 `SIM` 字符串，或者刷新旧快照时间，不能通过这条重新校验的入口。

仍使用原来的 TAKEOFF → 有限 WAYPOINT／驻留／转向 → LOITER → LAND 编译器，
保留全程预算、围栏、相对高度、HOME、接受半径和 wire 校验，不另写一套飞控。
旧 v1 行为保留；未迁移的 VTOL、固定翼、HIL／REAL 入口仍拒绝未经核验的 v2。

这份编译绑定**不是飞行授权**。它不认证传感器发送者，不执行实时容器检查，不造
PASS／OperatorGrant，不上传、不 ARM、不启动；原件 SHA 只是身份绑定。实际执行
仍需要当前会话检查、真正的验证报告、显式一次性 SIM 意图以及持久 Mission 事务。
重新打开冻结的命令文件只能验证当时的编译，不能让其变成当前实时许可。

## 已修复的通信问题

教师 GCS 使用 `255/190`，旧 Mission 上传／回读只接受 `250/191`。现在编号可以显式
传入，并在第一次发送前核对实际 MAVLink sender 的身份。错误组件、其他 GCS 和
广播不能推进本事务，非法数字类型不被强转；旧默认编号的调用仍兼容。

没有因此增加第二个遥测接收者，也没有将当前只读 sender 变成任意控制发送器。
实际接线仍需一个窄 Mission 发送 façade，让唯一 RX/send owner 执行发送、原日志先
持久化、主线程从同一来源过滤队列消费事务响应。

## 预训练模型与后续训练

本轮三个子智能体并行完成输入桥、通信修复与独立模型查验。补查了 MiniCPM-Robot、
MolmoAct2、GR00T；小权重文件不等于整套依赖能装进 8GB，更不等于能飞无人机。
MiniCPM 的地面跟随／机械臂接口不能改名成飞行动作；MolmoAct2 更适合离线方法对照；
GR00T 还有资源和固定许可冲突要处理。OpenFly 仍是更贴近航空导航的质量对照，但其
位姿回路也不能替代真实 PX4 动力学执行。详见[本轮固定来源研究](onboard-pretrained-action-research-20261008-r3.md)。

下一步是完成原点／路线净空与唯一 sender 的事务接线，在一次起飞里采集多个真实
动作段，保存命令、执行响应、实际前后姿态／位移与后继图像。审核后再训练动作
模型，按独立整场景留出评价；教师目标与实际执行结果分开保存，不用计划坐标或
生成视频冒充真实动作，不只因 loss 下降就替换默认模型。

本轮自动化结果见[软件集成证据](evidence/onboard-teacher-sim-planning-admission-20261008-r1.json)。
最终669项核心／协议测试及122项文档／parity／索引回归通过，源码与证据内容绑定复核通过。
没有新权重下载、模型加载／推理、优化器更新、Mission 上传、ARM 或飞行；r33 默认
模型和 `0.3.0-pre.8` 保持不变，最终发布与 HIL／REAL／Jetson／室外 GNSS 仍未通过。
