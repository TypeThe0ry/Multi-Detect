# 慢模型 r15 结果（2026-10-18）

结论：**不替换 r12**。r15 把“极小目标认不出来”这个问题基本补上了，但又一次变得太爱说“是”——在真实飞行评测集上，干扰物拒绝从 95% 掉到 73%。机上身份判断继续用 v2-r12-multi。

## 这一轮做了什么

- 补采：20 个专门生成的世界、80 个架次中完成 76 个（专家教师找到目标就停，平均每架次约 23 帧，共 1,820 帧，比计划少很多）。
- 新增训练行：训练 1,085 行、验证 105 行；按候选框短边粗算，<12 px 约 240 行、12–16 px 约 200 行。
- 合并：r12 训练集按类别/尺寸/正负比例抽 25% 回放（938 行），加上全部 r15 新行；新行以真目标为主，为了不重蹈 r13（复制正样本 → 爱说“是”）的覆辙，再从 r12 没被抽中的部分补约 300 条真实难反例，使合并后正样本占比 0.410（r12 为 0.400）。
- 训练：从 r12 适配器热启动，1 个 epoch、582 步、31 分钟，平均 loss 0.015。

## 评测（同一评测集、同一推理设置 fast_identity，Q5_K_M）

| 指标 | r12 | r15 |
|---|---:|---:|
| v3 集（当前候选框口径，233 行）身份准确率 | 78.5% | **90.1%** |
| v3 真目标召回 | 66.7% | **96.6%** |
| v3 干扰物拒绝 | **90.5%** | 83.6% |
| v1 真实飞行集（1,900 行）身份准确率 | **92.8%** | 82.5% |
| v1 干扰物拒绝 | **95.0%** | 73.0% |
| v1 真目标召回 | 90.2% | 93.7% |

v3 集按候选框短边分层（r12 → r15）：

| 短边 | 样本 | 真目标召回 | 干扰物拒绝 | 准确率 |
|---|---:|---|---|---|
| <12 px | 77 | 46% → **92%** | 90% → 88% | 69% → 90% |
| 12–16 | 43 | 73% → 100% | 81% → 76% | 77% → 88% |
| 16–20 | 37 | 88% → 100% | 85% → 77% | 86% → 92% |
| 20–32 | 40 | 59% → 100% | 100% → 89% | 78% → 95% |
| ≥32 | 36 | 92% → 92% | 96% → 83% | 94% → 86% |

v1 真实飞行集上 r15 的分层：<12 px 拒绝 91%、12–16 px 87%，但 16–20 px 只有 47%、20–32 px 69%、≥32 px 75%——问题集中在中等大小的候选上。

## 为什么

r15 新增数据几乎都是“这个就是目标”（找到目标的架次），中等大小的“长得像但不是”的反例很少；合并时补的反例来自 r12 的旧场地，覆盖不到 r15 世界里新出现的干扰物组合。模型学到了“小框也要认”，同时也学到了“中等大小的东西多半是目标”。

## 下一步（建议）

1. 用同一批 r15 世界补采干扰物视角：让教师专门飞向场地里的易混物体（不是目标）并记录，按 16–32 px 补成对难反例，再训一轮，验收仍按 v1/v3 分层看。
2. 或者按尺寸分工：<16 px 的候选交给 r15、其余仍交给 r12。两个模型各 1.26 GB，机上同一时刻只能放一个，这条路要先在 Orin 上测切换代价，暂不推荐。
