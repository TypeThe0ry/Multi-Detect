## 改动与数学约定

运行时仅使用已测量的单位射线 `d_i`。平均信息矩阵为：

`M = (1/N) Σ (I - d_i d_iᵀ)`，`trace(M)=2`。

三维各向同性几何的三个特征值都是 `2/3`。以此作无量纲归一化，残差的弱方向增益为：

`gain = sqrt(max(1, (2/3) / λ_min(M)))`。

保留原坐标求解次序、0.5 m 噪声下限、像素角噪声项及 `sigma_scale`；只将原残差项替换为 `residual × gain`。平均矩阵不随样本数乘 N，公式也不除 `sqrt(N)`。它把残差看作可能含相关姿态/标定误差的界，不假设连续帧独立，重复整组相同视角不会虚假收紧。它不是完整三维协方差，也不能发现所有射线一致偏到同一错误交点的共模偏差。

对称 3×3 最小特征值使用纯 Python 解析式，没有新增 NumPy 运行依赖。完全退化仍由原求解/基线/夹角门拒绝；没有改变任何确认门槛、匹配半径、去重半径或报告过滤规则。离线 `evaluate_onboard_ranging_reuse.triangulation_quality` 复用同一增益，保持运行与离线质量估计一致；其已有 `if tq` 调用分支兼容无质量结果。

原 4-ray fixture 的增益为 9.074，三角化 sigma 调整为 21.690 m。融合仍使用地面和三角化两源，得到 `(7.332,-16.037)`、sigma 9.229 m；并非无条件选择 ground。既有 4 m 去重规则现在识别出对 t7 的重复观察，最终保留前三个 finding。原始第 4 项 record 本身仍能在 fixture 中复现 4 个 finding，原失败没有被删除或改分。
